In-car adjustments by voice

Say "TC up one", "front bar softer", "bias to 54.5"… The engineer presses iRacing's own black-box keys — F8 (in-car adjustments), Up / Down (pick a control), Left / Right (change it), and = / - (brake bias) — and reads the new value back from the car. Keys only go to the iRacing window, and only on a straight. The first time in each car he learns the black box by nudging each item one click and putting it straight back (best done on an out lap). If you've moved those keys to other buttons in iRacing, put the keyboard keys back too (both can be bound).

VR colour (ReShade)

Colour for the headset through ReShade's OpenXR layer. Changes here only work with iRacing closed: ReShade starts with the sim and saves its own settings when the sim closes. Switching the layer on or off is a Windows-wide setting, so Windows asks for permission each time (nothing changes if you say no). If iRacing crashes at start after switching it on, switch it off here.
